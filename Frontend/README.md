# JobSync AI - Frontend

JobSync AI is a premium, modern, and interactive job matching web application. It features automated resume parsing, interactive matchmaking score visualization, and robust role-based routing (Students & Recruiters), fully optimized with an adaptive theme engine (Light & Dark modes) and micro-animations.

This guide provides instructions to download, install dependencies, and run the project locally.

---

## 🛠️ Prerequisites

Make sure you have the following installed on your system before proceeding:

* **Node.js**: Version `18.0.0` or higher (LTS recommended)
* **npm**: Version `9.0.0` or higher (normally bundled with Node.js)

---

## 🚀 Getting Started & Installation

Follow these steps to set up the project on your local machine:

### 1. Clone or Download the Project
Extract the project folder if you downloaded it as a ZIP, or clone the repository to your local computer.

### 2. Install Dependencies
Open your terminal (PowerShell, Command Prompt, or Bash), navigate into the project directory, and run the following command to download and install all required packages:

```bash
npm install
```

This will automatically read the `package.json` file and fetch all dependencies including React 19, Vite, Framer Motion, TailwindCSS, and Lucide React.

---

## 💻 Running the Project

Once the installation is complete, you can use the following scripts to run or build the project:

### Run Development Server
To launch the project in development mode with Hot Module Replacement (HMR):

```bash
npm run dev
```

* Once started, the terminal will display a local URL (usually `http://localhost:5173`).
* Open that link in your browser to view the application.

### Build for Production
To bundle and optimize the application files for production deployment:

```bash
npm run build
```

* The production-ready files will be generated inside the `dist/` directory.

### Preview Production Build
To spin up a local server to test and preview the production build generated by the build script:

```bash
npm run preview
```

## ✨ Primary Features Built
* **Explainable AI Score Ring**: Uses custom animated SVG rings color-coded (Green/Amber/Red) to reflect applicant compatibility.
* **Step-by-step Timeline**: A customized 3-step marketing timeline on the landing page that features a glowing connector pulse line sweeping left-to-right every 25 seconds.
* **Global Theme Selector**: Fully interactive toggle to swap dynamically between a futuristic Dark mode and a clean Light mode without reloading.
* **Spotlight Inputs**: Interactive form blocks in Login and Register that track the mouse position for a radial glow effect.
